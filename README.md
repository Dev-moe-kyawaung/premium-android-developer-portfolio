

# Premium Android Developer Portfolio

## ✨ Features

- **Premium UI/UX**
  - Clean, modern layout optimized for recruiters and clients
  - Mobile‑first, responsive design
  - Smooth animations and transitions
- **Tech Stack**
  - Vite + TypeScript
  - Tailwind CSS (or your preferred styling)
  - Modular, maintainable project structure
- **Developer‑Focused Content**
  - Highlighted Android projects with case‑study style descriptions
  - Skills section: Kotlin, Jetpack Compose, MVVM/MVI, Clean Architecture, etc.
  - Clear call‑to‑actions for contact and collaboration
- **Production Ready**
  - Optimized build with Vite
  - GitHub Actions CI/CD for automatic builds and deployment
  - Ready for GitHub Pages hosting

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ and npm/pnpm
- Git

### Install & Run Locally

```bash
# Clone the repo
git clone https://github.com/Dev-moe-kyawaung/premium-android-developer-portfolio.git
cd premium-android-developer-portfolio

# Install dependencies
npm install

# Start dev server
npm run dev

```
